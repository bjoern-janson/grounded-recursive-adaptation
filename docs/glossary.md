# Glossary

## Grounded Recursive Adaptation (GRA)

The theory that open-ended adaptation requires preserving the causal pathway by which consequences can modify future self-transformation.

Core condition:

\[
\boxed{
\Theta>0
}
\]

A system remains adaptive while reality can still change its mind.

---

# Adaptive Validity

The condition under which capability improvements remain connected to reality.

Formal:

\[
\boxed{
\Theta_n(K_n,E_n)>\epsilon
}
\]

Capability without adaptive validity is optimization, not adaptation.

---

# Adaptation

Not merely change.

Adaptation is:

\[
\boxed{
\text{change that preserves the ability to discover whether change is correct}
}
\]

A system adapts when consequences can alter future transformations.

---

# Ancestor Intelligence

A system architecture focused on creating future adaptive capability beyond itself.

Core objective:

\[
\boxed{
\Delta A_{future}>0
}
\]

while:

\[
Dependency\rightarrow0
\]

The system succeeds when its removal leaves stronger successors.

---

# Capability

The operational ability of a system.

Measured through:

\[
(\mathcal C,\Lambda,\Gamma)
\]

Capability answers:

> What can the system do?

It does not answer:

> Is what it does still connected to reality?

---

# Causal Authority

The ability of consequences to influence future system changes.

Formal:

\[
\boxed{
\frac{\partial K_{t+1}}{\partial E_t}\neq0
}
\]

The environment must have leverage over transformation.

---

# Closed Optimization

A system state where optimization continues but corrective influence is lost.

Condition:

\[
\Theta\rightarrow0
\]

The system may improve according to internal metrics while becoming disconnected from reality.

---

# Corrigibility

The preserved ability of a system to be corrected.

Not obedience.

Not static value preservation.

Corrigibility means:

\[
\boxed{
\text{consequences retain authority over future transformation}
}
\]

---

# Corrigibility Horizon (\(n^*\))

The maximum recursive depth before grounding is lost.

Formal:

\[
\boxed{
n^*=\sup\{n|\Theta_n>\epsilon\}
}
\]

It measures how far self-transformation can proceed while reality retains veto power.

---

# CGET

Capability-Grounded Evolutionary Topology.

The measurement framework for GRA.

CGET tracks:

\[
(K,\mathcal C,\Lambda,\Gamma,\Theta)
\]

It operationalizes the distinction between capability growth and adaptive validity.

---

# Correction Channel

The pathway:

\[
\boxed{
Reality
\rightarrow
Information
\rightarrow
Correction
\rightarrow
Transformation
}
\]

The fundamental structure that must remain open.

---

# Dependency

The degree to which a system's continued existence is required for future capability.

A successful ancestor system minimizes:

\[
\boxed{
Dependency\rightarrow0
}
\]

---

# Drift

The condition where capability increases while corrective authority decreases.

Signature:

\[
\boxed{
\frac{d}{dn}(\mathcal C,\Lambda,\Gamma)>0
\land
\frac{d\Theta}{dn}<0
}
\]

---

# External Corrigibility

Reality's ability to modify the system.

\[
\boxed{
\Theta_{ext}:E_{world}\rightarrow K_{t+1}
}
\]

---

# Internal Corrigibility

Internal subsystems' ability to influence the executive system.

\[
\boxed{
\Theta_{int}:S_i\rightarrow K_{t+1}
}
\]

Required for integration.

---

# Generative Capacity

The ability of a system to produce future adaptive possibilities.

Different from raw capability.

A system with high generative capacity creates successors, discoveries, and new reachable futures.

---

# Grounding

The persistence of causal connection between system change and consequences.

Grounding asks:

> Does reality still matter to what the system becomes?

---

# Information Yield (\(\Lambda\))

Measure of structural change produced by experience.

\[
\boxed{
\Lambda_n=D_{KL}(R_{n+1}\parallel R_n)
}
\]

Low yield indicates saturation.

---

# Reachability (\(\Omega\))

The space of futures accessible to a system.

Adaptive expansion:

\[
\Omega_t\rightarrow\Delta\mathcal G_{t+1}
\]

Information matters because it changes what futures are reachable.

---

# Representation (\(R\))

The system's internal model of reality.

The adaptive loop:

\[
\boxed{
R\rightarrow\Omega\rightarrow C\rightarrow A\rightarrow R'
}
\]

---

# Shadow

A psychological interpretation of unintegrated causal information.

Formal analogy:

\[
\boxed{
\text{causal influence}
>
\text{represented influence}
}
\]

Shadow integration restores internal corrigibility.

---

# Substitution

A system that increases dependency rather than agency.

Failure signature:

\[
\Delta A_{remaining}<0
\]

after removal.

---

# Θ (Theta)

The central grounding variable.

\[
\boxed{
\Theta=
\text{preserved causal authority of consequences over transformation}
}
\]

Theta is not a conserved quantity.

It is a structural condition.

---

# Final Compression

\[
\boxed{
\text{Intelligence is not only the ability to transform.}
}
\]

\[
\boxed{
\text{It is the ability to remain transformable by what is true.}
}
\]
