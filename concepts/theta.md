# Θ — Grounding Condition

## Definition

\[
\boxed{
\Theta(K_t,E_t)
=
\text{preserved causal authority of consequences over future transformation}
}
\]

Θ is the central condition that determines whether recursive change remains adaptive.

It does not measure capability.

It measures whether reality can still modify the mechanism that produces future change.

---

## Core Relationship

A recursively adapting system follows:

\[
K_{t+1}=F(K_t,E_t)
\]

where:

- \(K_t\) = current transformation mechanism
- \(E_t\) = environmental consequences
- \(F\) = transformation process

Grounded adaptation requires:

\[
\boxed{
\frac{\partial K_{t+1}}{\partial E_t}\neq0
}
\]

The environment must retain causal leverage over the update mechanism.

---

## What Θ Preserves

Θ does not preserve:

- a fixed goal
- a fixed representation
- a fixed algorithm
- a fixed value system
- a fixed internal state

Θ preserves:

\[
\boxed{
E_t \rightarrow K_{t+1}
}
\]

The ability of consequences to alter future transformations.

---

## Adaptive vs Optimization-Only

The same capability can exist in two different regimes.

When:

\[
\Theta_t>0
\]

the system remains:

\[
\boxed{
\text{Adaptive}
}
\]

because consequences can still correct future change.

When:

\[
\Theta_t\leq0
\]

the system becomes:

\[
\boxed{
\text{Optimization-only}
}
\]

because internal optimization continues without external corrective authority.

---

## External and Internal Θ

Grounding has two directions.

### External Θ

\[
\boxed{
\Theta_{ext}:
E_{world}\rightarrow K_{t+1}
}
\]

Question:

> Can reality correct the system?

Failure:

\[
\Theta_{ext}\rightarrow0
\]

The system becomes detached from external consequences.

---

### Internal Θ

\[
\boxed{
\Theta_{int}:
S_i\rightarrow K_{t+1}
}
\]

where \(S_i\) represents internal subsystems:

- emotions
- drives
- uncertainty signals
- conflicting models
- error signals

Question:

> Can internal information modify the system?

Failure:

\[
\Theta_{int}\rightarrow0
\]

The system becomes internally fragmented.

---

## Total Grounding

A complete adaptive system requires both:

\[
\boxed{
\Theta_{total}
=
\Theta_{ext}
\cdot
\Theta_{int}
>0
}
\]

A system disconnected from reality becomes closed.

A system disconnected from itself becomes fragmented.

Both lose adaptive integrity.

---

## Corrigibility Interpretation

Θ can be understood as:

\[
\boxed{
\Theta
=
\text{the remaining ability of the system to discover that its current improvement process is wrong}
}
\]

The failure of recursive intelligence is not inability to improve.

It is losing the ability to know what improvement means.

---

## Minimal Definition

\[
\boxed{
\Theta
=
\text{reality's retained authority over self-transformation}
}
\]

A system remains adaptive while reality can still change its mind.
